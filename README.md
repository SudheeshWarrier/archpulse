# ArchPulse

ArchPulse turns static architecture diagrams into simple step-by-step animated walkthroughs.

Upload an SVG diagram, choose the important shapes and flows, and play it back as a clear story for reviews, demos, planning sessions, or team discussions.

ArchPulse is currently in **BETA**, so the experience is still evolving.

Use the tool here: [https://archpulse.in/](https://archpulse.in/)
